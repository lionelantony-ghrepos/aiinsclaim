### User story

As a claims ops admin, I edit decision tables and parameters in a UI with draft/simulate/activate.

### Scope

Admin rules pages, DecisionTableGrid editor, simulation drawer, parameters CRUD.

### Definition of done

Admin can change stp.max_amount and see behavior change; AC-008-01..05.
