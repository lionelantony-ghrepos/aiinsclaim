## Surfaces

- `src/lib/sla/` — timers, sweep, auth, elapsed ratio
- Hooks: `src/lib/state-machine/index.ts` (`transitionClaim`), `src/lib/db/queries/tasks.ts` (`insertTask`, `updateTask`)
- `src/app/api/sweep/sla/route.ts` — cron-facing sweep
- `src/app/(app)/(admin)/sla/` — admin manual trigger
- `src/app/(app)/(staff)/claims/[id]/page.tsx` — active SLA timers panel

## Contracts

- POST `/api/sweep/sla` — header `x-sweep-secret` must match env `SWEEP_SECRET`; 401 `{ ok: false, error: { code: "UNAUTHORIZED" } }`; 200 `{ ok: true, data: { scanned, escalated } }`
- Server action `runSlaSweepAction()` — admin only; returns `Result<SlaSweepSummary>`

## Rules

- BR-SLA-001 — timer definitions (trigger → timer_code, duration from parameters, pause flag)
- BR-ESC-001 — escalation tiers keyed by `breach_count` (actions: notify, notify+bump, reassign+escalation task, critical supervision task)
- Escalation threshold ratios loaded from `parameters` keys `sla.esc.*` (not duplicated in code)

## How to extend

- Add a new BR-SLA-001 row + parameter duration key in seed; map claim status in `slaTriggerForStatus` / `TIMER_CODE_BY_CLAIM_STATUS` if stage-owned
- Add escalation tier: parameter ratio + BR-ESC-001 rule row; sweep picks up via `ESCALATION_TIERS`
- Production: cron POST `/api/sweep/sla` with `x-sweep-secret` (see README)

## Ops

- Env: `SWEEP_SECRET` (see `.env.example`)
- Injected clock: pass `now?: Date` to timer and sweep functions (Vitest)
- Durations and task SLAs: `parameters` table only (`sla.*`, `sla.task.*`)
