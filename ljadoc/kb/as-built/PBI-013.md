- Routes: `(staff)/queue`, `(staff)/queue/[taskId]`
- Components: `QueueList`, `QueueFilters`, `ResolveDialog`, `BulkReassignDialog`, `TaskDetailClient`; enhanced `AgentProposalCard`, `TaskCard`
- DB helpers: `src/lib/db/queries/tasks-queue.ts`
- Seed: `seed/generators/tasks.ts` (7 demo tasks across queues + SLA timers)

## Contracts

- Zod: `src/lib/schemas/tasks.ts` (`ListQueueSchema`, `ResolveTaskSchema` with `REASON_REQUIRED`, `BulkReassignSchema`, …)
- Server actions: `src/app/(app)/(staff)/queue/actions.ts` (`fetchQueueAction`, `resolveTaskAction`, `claimTaskAction`, `releaseTaskAction`, `bulkReassignAction`)
- API routes: `POST /api/queue/list`, `POST /api/tasks/resolve`
- Generated reference: [generated/schemas-catalog.md](../generated/schemas-catalog.md)

## Rules

- Consumes triage/fraud/extraction agent payloads in `tasks.payload_json` (no new BR-* tables)
- Role → queue map in `src/lib/auth/scope.ts` (`ROLE_QUEUE_ACCESS`)
- Entitlements: staff queue roles via `requireRole()`; bulk reassign supervisor/admin only

## How to extend

- Poll interval: change `parameters.ui.queue_poll_seconds` (never hard-code in components)
- New queue tab: extend `TASK_QUEUES`, `ROLE_QUEUE_ACCESS`, and seed tasks
- PBI-014: SLA sweep will update timer breach state consumed by breach filter
