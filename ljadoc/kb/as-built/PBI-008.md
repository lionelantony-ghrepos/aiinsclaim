## Contracts

Server actions per [API-CONTRACTS](../API-CONTRACTS.md) §admin:

- `createDraftVersion`, `updateDraftRows`, `simulateVersion`, `activateVersion`, `upsertParameter`
- Form actions with redirect for create draft, activate, parameter save
- Errors: `VERSION_NOT_DRAFT`, `OVERLAPPING_EFFECTIVE`, `ImmutableVersionError`

## Rules

- All nine seeded BR-* rule sets editable (no new code creation)
- `simulateVersion` uses `evaluateVersionById` with `dryRun: true` (no `rule_audit_log`)
- Parameter changes affect live evaluation via `parameters` table (e.g. `stp.max_amount` → BR-STP-001)
- Entitlements: `requireRole("admin")` + `assertCanWriteRules` on all mutations

## How to extend

- Add read helpers in `rules-read.ts` for diff/comparison views
- Register new input schemas in `src/lib/rules/schemas.ts` when adding BR-* sets (seed-only until product allows creation)
- Call `clearParameterCache()` after any parameter upsert

## Ops

- Admin login: `admin@demo.local` / demo password from seed
- E2e requires fresh seed (`npm run seed`) when re-running locally with `reuseExistingServer`
- Test harness: isolated DB in Vitest; Playwright serial suite `pbi-008.spec.ts`
