## Contracts

- Zod schemas: `SummaryAgentInputSchema`, `SummaryAgentOutputSchema` in `src/lib/schemas/agents/summary.ts`
- Server actions: `regenerateSummaryAction(claimId)` in `actions.ts`
- `emitMaterialChange(db, claimId, kind)` — fire-and-catch; debounce via `ui.summary_debounce_s` parameter
- AGT-SUMMARY mock in `callAiGateway`; `claimId.includes('gateway-fail')` triggers failure path

## Rules

- No new decision tables.
- Reads: `claim_state_history`, `agent_runs`, `rule_audit_log`, `fraud_scores`, `reserves`
- Debounce parameter: `ui.summary_debounce_s` (numeric seconds; defaults to 0 if not seeded)
- `requireRole('adjuster', 'supervisor', 'admin', 'intake_agent', 'siu_analyst')` on regenerate action

## How to extend

- Add new `emitMaterialChange` trigger kinds by calling with a new `kind` string
- Seed `ui.summary_debounce_s` in `parameters` table to enable debounce (e.g. `{"valueJson": 30}`)
- Wire reserve changes from PBI-015 confirm action by calling `emitMaterialChange(db, claimId, 'reserve_change').catch(() => {})`

## Ops

- Mock gateway in CI; no live AI credentials needed
- `ui.summary_debounce_s` parameter is optional; missing → 0s debounce (always regenerate)
- Schema changes applied via direct SQLite ALTER TABLE (FK constraint prevented drizzle-kit push --force)
