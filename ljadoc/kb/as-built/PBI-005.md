- Loaders: `seed/loaders/full-seed.ts`, `seed/loaders/rules.ts`
- Assets: `seed/assets/` (~20 sample files)
- Scripts: `npm run seed`, `seed:rules`, `seed:demo`

## Contracts

Deterministic faker seed 42; volumes per DATA-DICTIONARY §6.1–6.3. Exported `runSeed(db, sqlite)` for tests.

## Rules

Seeds all BR-* rule sets v1 + parameters; claims beyond draft invoke BR-TRIAGE-001, BR-FRAUD-001, BR-RESERVE-001 via `evaluateRuleSet` (PBI-006).

## How to extend

Add generator modules under `seed/generators/`; extend `full-seed.ts` orchestration. New rule thresholds go in `seed/definitions/parameters.ts`.
